## Variant: Calm Editorial

### Design stance
Ghost as a quiet literary journal — typography-forward, spacious, serif display for emotional moments, clean utility sans for actions. The encounter feels like a written entry, not a UI card.

### Key choices
- **Layout:** Single-column, generous whitespace, grid-based encounter cards with glyph + content separation
- **Typography:** Cormorant Garamond (serif) for display/emotional moments; Inter (sans) for UI/utility; monospace for Ghost IDs
- **Color:** Warm neutral dark (#0a0a0c) with warm accent (#e8dcc8) for waiting states, cool accent (#d4d4dc) for mutual/connected
- **Interaction:** Subtle motion (fade, scale), glyph state changes (border/color), mutual reveal as a centered moment

### Trade-offs
- Strong at: Emotional resonance, reading clarity, feeling like a "place" not an app
- Weak at: Density (may feel too sparse on desktop), action visibility (CTAs are subtle)

### Best for
Users who value atmosphere over efficiency; the "quiet romantic" core audience.

## Variant: Intimate Atmospheric (to be built)

### Design stance
Ghost as a private moment — darker, more immersive, the encounter feels like a memory surfacing. Less editorial, more sensory.

### Key choices
- **Layout:** Full-bleed encounter cards, glyph as a central atmospheric element
- **Typography:** Single typeface family (system serif for display, sans for UI), more weight variation
- **Color:** Deeper dark (#050507), subtle warmth only on reveal
- **Interaction:** Layered reveals, glyph as a breathing pulse, mutual reveal as a slow unfurl

### Trade-offs
- Strong at: Mystery, immersion, "memory" feeling
- Weak at: Scannability, may feel too dark for some contexts

### Best for
Late-night use, users who want mystery over clarity

## Variant: Minimal Utilitarian (to be built)

### Design stance
Ghost as a precise tool — clean, functional, the encounter is a clear record. Minimal emotion in UI, maximum clarity.

### Key choices
- **Layout:** Compact cards, dense information hierarchy, minimal ornamentation
- **Typography:** Single sans-serif (system), weight/size for hierarchy only
- **Color:** True black (#000), single accent, high contrast
- **Interaction:** Instant state changes, no decorative animation

### Trade-offs
- Strong at: Speed, clarity, efficiency
- Weak at: Emotional resonance, "romantic" quality

### Best for
Power users, daytime use, accessibility-first contexts
