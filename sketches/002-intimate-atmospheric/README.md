## Variant: Intimate Atmospheric

### Design stance
Ghost as a private memory surfacing — darker, more immersive, the encounter feels like a half-remembered moment. Glyph breathes with state; mutual reveal unfurls slowly.

### Key choices
- **Layout:** Full-bleed vertical cards, centered content, glyph as atmospheric centerpiece
- **Typography:** DM Serif Display (serif) for display; DM Sans (sans) for UI; monospace for IDs
- **Color:** Deep dark (#050507), warm accent (#c8b8a0) with subtle glow, minimal cool tones
- **Interaction:** Glyph pulses on wait/notification, mutual reveal unfurls with scale+fade, subtle glow shadows

### Trade-offs
- Strong at: Mystery, immersion, "memory" feeling, emotional weight of reveal
- Weak at: Scannability, density (may feel too sparse), glow may not suit all contexts

### Best for
Late-night use, users who want mystery over clarity, the "slightly romantic" core experience

## Variant: Minimal Utilitarian (to be built)

### Design stance
Ghost as a precise tool — clean, functional, the encounter is a clear record. Minimal ornamentation, maximum clarity.

### Key choices
- **Layout:** Compact cards, dense information, no decorative glyphs
- **Typography:** Single sans-serif (system), weight/size for hierarchy only
- **Color:** True black (#000), single accent, high contrast
- **Interaction:** Instant state changes, no decorative animation

### Trade-offs
- Strong at: Speed, clarity, efficiency, accessibility
- Weak at: Emotional resonance, "romantic" quality, mystery

### Best for
Power users, daytime use, accessibility-first contexts
