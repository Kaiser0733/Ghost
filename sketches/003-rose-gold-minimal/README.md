# Variant: Rose Gold Minimal

## Design stance
Restrained minimalism with clean lines, reduced visual weight, and faster transitions. The anonymous presence is a simple ring with inner pulse. Mutual reveal uses a clean 500ms animation without elaborate effects.

## Key choices
- **Layout:** Tighter spacing, smaller radius (12px), single ambient gradient
- **Typography:** Same hierarchy, faster reveal animation (500ms)
- **Color:** Clean base (#110d0e), card surface (#1c1517), minimal gradients
- **Interaction:** No hover top-line, no aura, no expanding ring, bottom nav without indicator bar, minimal pulse on anonymous presence

## Trade-offs
- Strong at: Performance, clarity, speed, lightweight feel
- Weak at: Atmospheric depth, emotional immersion, premium feel

## Best for
- Users who prefer utility over atmosphere
- Lower-end devices
- Daytime usage where heavy dark modes feel oppressive
