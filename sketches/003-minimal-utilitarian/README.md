## Variant: Minimal Utilitarian

### Design stance
Ghost as a precise tool — clean, functional, the encounter is a clear record. Minimal ornamentation, maximum clarity. No decorative glyphs, no emotional typography.

### Key choices
- **Layout:** Compact grid cards (48px marker + content), dense information, no decorative whitespace
- **Typography:** Single system sans-serif, weight/size for hierarchy only, no serif
- **Color:** True black (#000000), single white accent, high contrast, no warm tones
- **Interaction:** Instant state changes, no decorative animation, no glyph breathing/pulse

### Trade-offs
- Strong at: Speed, clarity, efficiency, accessibility (high contrast, no motion)
- Weak at: Emotional resonance, "romantic" quality, mystery, memorability

### Best for
Power users, daytime use, accessibility-first contexts, users who prefer function over form
