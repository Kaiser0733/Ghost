# Variant: Rose Gold Editorial

## Design stance
Content-first editorial approach with generous whitespace, Playfair Display serif for all emotional copy, and rose-gold as a restrained signature accent. The encounter card is a designed object with clear visual hierarchy and a custom anonymous-presence illustration.

## Key choices
- **Layout:** Single-column, centered, generous vertical rhythm
- **Typography:** Playfair Display for headlines/leads/usernames; system UI sans for body/meta; monospace only for Ghost IDs
- **Color:** Deep rose-charcoal background (#0f0b0c), rose-toned card surface (#1a1416), #B76E79 accent for actions/reveal states, warm ivory text
- **Interaction:** Subtle breath/pulse animations on glyphs, 600ms choreographed mutual reveal with staged emergence, hover/tap states on all interactive elements

## Trade-offs
- Strong at: Emotional resonance, readability, brand recognition, premium feel
- Weak at: Information density (fewer items visible), may feel sparse on desktop

## Best for
- Mobile-first experience where emotional impact matters more than density
- Users who value calm, editorial quality over feature-rich interfaces
